# Loon-CampusNet

手机端校园网自动认证 Loon 插件（锐捷/深澜 ePortal V3）。

## 安装

1. Loon → 配置 → 插件 → 右上角 + → 从 URL 安装插件
   安装链接：`https://raw.githubusercontent.com/zjhenrynsyh/Loon-CampusNet/main/CampusNetHelper.plugin`
2. 在插件「设置」里填写学号和密码
3. 启用插件即可，掉线自动重连

> 说明：账号密码仅保存在手机本机 Loon 配置里，不会上传。

## 依赖

- iOS 14+（脚本使用原生 BigInt）
- Loon 3.5.1(983)+（Script v2 对象参数语法）
